# Contributing to ShopSphere OpenCommerce

Thank you for your interest in contributing to ShopSphere!

## Contribution Guidelines
1. **Fork the Repository:** Create your personal fork on GitHub.
2. **Clone Locally:** `git clone https://github.com/sanikadound/ecommerce-cart-ui.git`
3. **Create a Feature Branch:** Always isolate changes on a dedicated branch (`git checkout -b feature-enhancement`).
4. **Code Quality:** Ensure pure semantic HTML5, accessible CSS variables, and clean vanilla ES6 JavaScript.
5. **Testing:** Run `python test_cart_engine.py` to ensure zero regressions in pricing calculations.
6. **Submit a Pull Request:** Open a PR referencing your issue number and provide before/after screenshots.
